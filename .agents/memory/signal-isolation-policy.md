---
name: Ambiguous source plans
description: Why ambiguous EdgeAI plans are isolated rather than selected by rank or changing historical identities.
---
When multiple source setups collapse into the same existing signal identity with conflicting financial plans, do not choose by array order, R/R or apparent edge. Isolate that identity while importing unrelated valid identities and retaining existing trades and original plans.

**Why:** The user requested a minimal, safe correction, explicitly allowing candidate-level isolation when no plan can be chosen with certainty. Adding strategy-specific historical identities would require a broader migration outside that scope.

**How to apply:** Keep source-version diagnostics explicit, including the conflicting source setup names and levels. Isolation is scoped to source and signal date; a different day's report must not clear an older identity's unresolved warning.
